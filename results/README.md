# Backtest results — REAL numbers

Generated by `python3 backtest.py` against real hourly OHLCV committed at
[alimohammadiamirhossein/CryptoPredictions](https://github.com/alimohammadiamirhossein/CryptoPredictions).

- **ADAUSD 1h:** 2021-09-29 → 2023-02-17 (12,150 bars)
- **DOGEUSD 1h:** 2021-09-29 → 2023-02-17 (12,150 bars)
- **ETHUSD 1h:** 2018-08-02 → 2023-02-17 (39,841 bars)

13 strategies × 3 assets × 1 TF = 39 combos.
Fees: 0.1% per side, slippage 0.05% per side. Long-only, next-bar-open entry,
intrabar SL/TP checks via bar high/low.

## Files

| File                          | What it is                                          |
|-------------------------------|-----------------------------------------------------|

| `summary.csv`                 | Every single combo, all metrics                     |
| `summary.json`                | `qualifying` + `grails` machine-readable            |
| `by_wr/NN_*.md`               | Per-combo detail + trade log (🏆 = grail)           |

4×ATR TP) turns that into +63.68% net on real data with realistic fees.

## What this dataset can't tell you

- **INJ:** not in the source dataset; would need Binance-reachable host.
- **5m / 15m TFs:** same — only 1h is committed to GitHub.
- **2023-2026 out-of-sample:** dataset ends Feb 2023.

Run `python3 fetch_data.py` on a machine with Binance access to extend
coverage. The pipeline reads any CSV named `{ASSET}_{TF}.csv` in `data/`.

## Reproduce

```bash
pip install -r requirements.txt
python3 tools/convert_cryptopredictions.py
python3 backtest.py --min-wr 0.60 --min-trades 5 --grail-dd 30
```
