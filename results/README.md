# Backtest results — REAL

Generated by `python3 backtest.py --min-wr 0.60 --min-trades 5` against real
hourly OHLCV for **ADAUSD**, **DOGEUSD**, **ETHUSD** pulled from
[alimohammadiamirhossein/CryptoPredictions](https://github.com/alimohammadiamirhossein/CryptoPredictions)
via `tools/convert_cryptopredictions.py`.

- **ADAUSD 1h:** 2021-09-29 → 2023-02-17 (~17 months, 12,150 bars)
- **DOGEUSD 1h:** 2021-09-29 → 2023-02-17 (~17 months, 12,150 bars)
- **ETHUSD 1h:** 2018-08-02 → 2023-02-17 (~4.5 years, 39,841 bars)

## What's in here

- `summary.md` — qualifying combos (WR>60%, trades>5), sorted by WR desc
- `summary.csv` — every strategy × asset × TF combo with all metrics
- `summary.json` — same as summary.md in machine-readable form
- `by_wr/NN_*.md` — one file per qualifying combo with trade log

## Headline finding

All 4 combos that pass WR>60% have **negative total return** on the full history.
That's the classic "high WR isn't an edge" trap — wins are small and losses are
large. Profit factor < 1 on all qualifying rows. **Filter on PF≥1.1 and return>0
if you want something actually tradable**, not just WR>60%.
