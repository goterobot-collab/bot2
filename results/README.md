## How to reproduce + extend

```bash
pip install -r requirements.txt

# 1. Pull real OHLCV from GitHub (works behind firewalls)
python3 tools/convert_cryptopredictions.py

# 2. Single-config backtest
python3 backtest.py --min-wr 0.60 --min-trades 5 --grail-dd 30

# 3. Random-search grail loop (Ctrl-C safe)
python3 grail_loop.py --iter 5000 --seed 42

# 4. Dedup + rank all grails found
python3 tools/rank_grails.py
```

## Honest disclosure

- **INJ** not in this dataset (listed too recently). Run `fetch_data.py` on
  a host with Binance reachability to add it.
- **5m / 15m** not in this dataset either. Same fix.
- Dataset ends **Feb 2023**. Every grail shown is in-sample. Before going
  live, re-run on 2023-01 → now as true out-of-sample.
- `bb_trend_rejoin` grails concentrate on DOGE/ETH — ADA also produced a
  few grails but with lower scores (see `top_grails.md`).
- Some grails have few trades (e.g., 8–13). Statistical significance is
  weak below ~30 trades. Rank score applies a penalty under 8 trades but
  you should still prefer the higher-trade-count rows for production.
